Account Security

Change Password

Securely update an authenticated user's password while enforcing complexity requirements.
Document IDADM-DOC-007
Version1.0
StatusDraft
Last Updated07/26/2026
Privacy, security, and administrative access notice

Administrative pages may display workforce identity, contact information, Provider identifiers, organizational structure, account status, and operational configuration. Screenshots in this guide use redacted or demonstration information. Access should be limited by role, Provider scope, and the minimum access necessary to complete authorized administrative duties.

Purpose

Change Password allows an authenticated user to replace their own password without exposing it to Provider administrators or True Care System support staff. Passwords are not displayed or auto-filled by the platform.

Fields and Validation

FunctionPurposeAdministrative control
Username / EmailIdentifies the authenticated account.Confirm the account belongs to you.
Current PasswordVerifies the user before change.Never share it.
New PasswordStores the replacement credential after validation.Use uppercase, lowercase, number, and special character.
Confirm New PasswordConfirms accurate entry.Must match exactly.
CancelLeaves without changing credentials.Use when the change is unintended.
Change PasswordSubmits the update.Reauthenticate if prompted.

Security Practices

  • Use a unique password.
  • Do not send passwords by email, text, announcement, or support ticket.
  • Change immediately when compromise is suspected.
  • Review Login History for unfamiliar devices, IP addresses, or failures.
