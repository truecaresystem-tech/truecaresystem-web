Provider Identity & Access

Users

Create, review, filter, edit, deactivate, reset, and assign roles for Provider accounts.
Document IDADM-DOC-002
Version1.0
StatusDraft
Last Updated07/26/2026
Privacy, security, and administrative access notice

Administrative pages may display workforce identity, contact information, Provider identifiers, organizational structure, account status, and operational configuration. Screenshots in this guide use redacted or demonstration information. Access should be limited by role, Provider scope, and the minimum access necessary to complete authorized administrative duties.

Purpose

The Users workspace manages authenticated accounts within the current Provider. Authorized administrators can create users, edit account information, assign roles, reset passwords, deactivate accounts, and review account status and last-login information.

Dashboard and Search

Total Users

Number of user accounts available within the Provider scope.

Active

Accounts currently permitted to authenticate.

Locked / Disabled

Accounts requiring administrative review.

Provider Admins

Accounts with Provider-wide administrative authority.

Search

Find users by name, email, or role.

Role / Status Filters

Narrow the register to the desired access group or account condition.

User Actions

FunctionPurposeAdministrative control
Create UserRegisters a new Provider user.Verify employment or legitimate business need.
EditUpdates allowed user information.Document material identity changes.
RolesAssigns one or more approved roles.Use least privilege.
ResetInitiates a secure password reset.Never send passwords in unsecured channels.
DeactivatePrevents future access while preserving history.Use promptly after termination or duty change.
DeleteRemoves an account only when policy and dependencies permit.Avoid when audit retention requires identity history.
