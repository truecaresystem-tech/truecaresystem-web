Privacy, HIPAA, and information-use notice

FAQ answers may reference PHI, workforce data, billing, payroll, authentication, support, or Provider configuration. Use minimum-necessary access, do not place sensitive values into public evidence, and follow approved Provider policies and roles.

Questions and Answers

Which browser should be used?
Use a current supported browser such as Microsoft Edge, Google Chrome, Safari, or another browser approved by the Provider.
What should I do when a page looks broken?
Refresh, confirm the correct stylesheet and script paths, clear stale cache, test another supported browser, and review recent deployments.
Why might one network fail while another works?
DNS, IP reputation, firewall, router, VPN, proxy, or ISP routing may affect access.
Why did an upload fail?
Check file type, size, network connection, permission, storage availability, and whether sensitive content is allowed.
Does device time matter?
Yes. Incorrect device date, time, or timezone can affect authentication codes, schedules, EVV, and audit timestamps.
What evidence helps technical support?
Exact URL, page, action, error message, date/time, Provider, role, browser, device, request ID, and redacted screenshot.

Need More Help?

Review the related module guide and Troubleshooting page first. Create a Provider-scoped support ticket when the question involves unresolved production behavior, PHI, security, billing, payroll, integrations, or data integrity.
